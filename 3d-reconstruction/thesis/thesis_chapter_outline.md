# 毕设章节大纲：基于生成先验引导的单视图大视角三维重建

> 路线：发现问题 → 研究现状 → 提出方案 → 解决问题 → 消融实验 → 分析讨论
> 说明：每小节标注【放什么图/表】，对应已有实验产物。

## X.1 引言与问题定义

**X.1.1 研究背景与意义**
- 单视图三维重建的价值（一张图重建可漫游 3D 场景）。
- 应用场景：VR/AR、内容创作、机器人。

**X.1.2 问题的提出**
- 单视图前馈重建（Flash3D）快速但在**大视角外推**下严重退化：拉糊、缺失区域无内容。
- 【图 1】baseline 大外推退化效果图（Flash3D big50 渲染 vs GT，来自 compare_big50.png 左右列）。
- 【表述】用 big30/big50 协议量化退化：FID 从近视角到 big50 显著上升。

**X.1.3 本章主要工作与贡献**
1. 提出测试时生成先验引导的单视图重建框架（零训练成本），在 RE10K 大视角外推上显著改善分布真实感（big50 FID 100.5→77.5，约 -23%）。
2. 提出 3D 循环一致性门控，针对生成幻觉给出显式可信度估计，在幻觉检测上显著优于 2D baseline（AUROC 0.9227 vs 0.7144）。
3. 在 RE10K + ACID 两数据集上系统评估生成先验的收益边界，证明保真修复先验与真实几何底座结合最可靠，并揭示 PSNR/LPIPS 分裂现象。

## X.2 相关工作（研究现状）

**X.2.1 单视图三维重建**
- 前馈式（Flash3D、Splatter Image）；优点快、缺点大外推退化。

**X.2.2 多视图新视角合成**
- MVSplat / CAT3D / pixelSplat：效果好但需多图，不适用单视图。
- 【表述】引用邮件里那张表的对比（MVSplat 3视图 PSNR 23.77 等），说明单视图任务的固有难度。

**X.2.3 生成模型用于三维/新视角**
- 图像修复（Difix）、视频扩散外推（ViewCrafter）、前馈 3D 生成（FlashWorld）。
- 各自机制与幻觉问题，引出"如何用好生成先验"的研究空间。

## X.3 方法

**X.3.1 整体框架**
- 【图 2】系统流程图（需画）：单图 → Flash3D 初始 3DGS + 相机轨迹 → 生成伪观测 → test-time 优化 → 大视角渲染。

**X.3.2 测试时生成先验引导**
- 伪观测作为监督信号的原理（不需逐像素等于 GT，只需提供合理约束）。
- test-time 优化目标：锚点约束 + 新视角伪观测监督 + LPIPS + 距离自适应权重。

**X.3.3 三维循环一致性门控（核心创新）**
- 动机：生成模型幻觉直接注入会污染 3D。
- 方法：回投可信度——真几何跨视角自洽、幻觉矛盾；逐像素加权注入。
- 【图 3】3D-cycle 可信度可视化（E836：精确标出幻觉区，对比 2D 方法只降权 6% vs 3D 27.8%）。**全章最亮的图，重点放大。**

## X.4 实验

**X.4.1 实验设置**
- 数据集：RealEstate10K 候选池 158 场景（各 bucket 有效样本数：tgt5=155、tgt10=158、tgt_rand=158、big30=117、big50=92）+ ACID 40 场景（每桶 n=40）。
- 外推协议：tgt5/tgt10/tgt_rand/big30/big50；各表必须单独标注有效 n，禁止笼统写成每桶 158。
- 主指标：FID（生成式新视角的分布真实感）；辅助指标：LPIPS（感知）、PSNR（像素）与幻觉检测 AUROC。
- LPIPS 口径：跨论文比较只用 VGG+5% crop；ACID AlexNet 结果仅用于同表内部方法比较并明确脚注。
- 实现细节：Flash3D 权重、800步优化、A6000。

**X.4.2 主结果：生成引导显著改善分布真实感**
- 【表 1】RE10K 四方法 × 五 bucket FID（baseline/Difix/naive/CycleFusion；候选池 158 场景，各 bucket 标注实际 n）。
- 正文/摘要优先展示四个 headline：
  1. RE10K big50：FID 100.51→77.49，**相对下降 22.90%**（n=92）。
  2. RE10K big30：FID 58.93→47.27，**相对下降 19.79%**（n=117）。
  3. 相比 naive-fusion，CycleFusion 在 big50 将 FID 83.25→77.49，**再下降 6.92%**（n=92）。
  4. ACID big50：FID 67.4→59.6，**相对下降 11.57%**（n=40），验证跨数据集泛化。
- 【图 4】RE10K big50 五列效果图（Flash3D|Difix|naive|CycleFusion|GT，来自 E841），重点展示退化渲染被锐化、鬼影减少、结构更干净。
- 叙事顺序：先给 RE10K/ACID 的 FID 正向结果，再讲门控消融；不要在主结果首屏展示 FlashWorld 的负面 LPIPS。

**X.4.3 三维门控消融：防止生成融合退化**
- CycleFusion vs naive-fusion：big30 FID 50.10→47.27（-5.65%，n=117）；big50 FID 83.25→77.49（-6.92%，n=92）。
- 结论：门控在引入生成先验时稳定阻止朴素融合退化；这一比较采用相同数据、相同优化器、相同生成源，只改变融合策略，因果关系最干净。
- **幻觉检测精度（创新点主指标）**：3D-cycle AUROC 0.9227 vs 2D baseline 0.7144，绝对提高 **20.83pt**、相对提高 **29.16%**（15 eval views）。【表5】
- 【图 5】门控翻盘案例 + 差异热力图（E841 diff：naive ghosting vs cycle 干净）。
- E863 全图 LPIPS 仅有 1e-4 量级改善，放在本节末尾或附录，表述为“在 Difix 强锚定下稳定不退化”，不作为 headline。

## X.5 生成先验的对比研究（深度分析）

**X.5.1 三种生成先验对比**
- 【表 2】RE10K：baseline/Difix/FlashWorld 端到端 LPIPS/PSNR。
- 【表 3】ACID：baseline/Difix/FlashWorld 三方（40场景，与 RE10K 对称）。

**X.5.2 LPIPS/PSNR 分裂现象**
- 两数据集一致：Difix 感知锐化（LPIPS 最好）、FlashWorld 像素平滑（PSNR 最好）。
- 【图 6】ACID 三方效果图（Flash3D|Difix|FlashWorld|GT，来自 E857）。

**X.5.3 级联联合实验**
- FlashWorld+Difix 级联，LPIPS 未改善、PSNR 微增。
- 【表 4】四方对比（Difix/FlashWorld/Cascade big50）。

**X.5.4 生成先验边界与数据集差异**
- ACID（自然风景）上 FlashWorld 相对 baseline 一致改善；RE10K（室内）上 FlashWorld 大外推拖累 LPIPS。
- E862 边界消融显示：在 RE10K 上无门控地引入 FlashWorld 会提高 PSNR 但伤 LPIPS，最佳感知质量仍来自 Difix。
- 结论：生成先验并非无条件有效，其收益依赖数据集分布、生成内容与真实几何的一致性；本文方法价值在于系统识别这种边界，并用 3D-cycle 给出幻觉可信度。

## X.6 讨论与本章小结

**X.6.1 核心发现**
1. 测试时生成引导能以零训练成本显著改善大外推分布真实感（RE10K big50 FID -23%，big30 约 -20%）。
2. 3D-cycle 门控能有效识别生成幻觉（AUROC 0.9227），并在融合生成先验时稳定优于朴素融合，避免 ghosting/退化。
3. **保真的关键在真实几何底座，而非生成模型的先进性**：Difix 信任 Flash3D 真实几何后效果最好；FlashWorld 想象几何提高 PSNR 但伤 LPIPS；级联也无法救回几何失配。

**X.6.2 局限性**
- 单视图大外推存在信息瓶颈，PSNR 提升有限。
- 门控在端到端全图 LPIPS 上收益较小（1e-4 量级），主要贡献体现在幻觉识别和防止朴素融合退化。

**X.6.3 本章小结**
- 承上启下，指向后续工作（更强几何底座、大 disocclusion 场景）。
