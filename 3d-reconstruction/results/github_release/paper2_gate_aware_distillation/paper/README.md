# Paper 2 LaTeX Package

Self-contained draft for **Selective Disocclusion Prior Distillation**. The paper
studies a student trained and evaluated on oracle-curated high-teacher-gain scenes
with visibility masks derived offline from the full target clip. This is an
upper-bound experiment, not deployable single-view inference.

## Build

```bash
cd ..
python3 scripts/check_claim_integrity.py
python3 scripts/generate_quality_speed.py
cd paper/figs
pdflatex -interaction=nonstopmode -halt-on-error fig_pipeline.tex
cd ..
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

The quality-speed figure is a vector PDF generated directly from the released
`../results/E-211_student_standard_metrics.json`. It reports the same fixed custom
21-scene/759-frame diagnostic and is not an official Flash3D-protocol comparison.

## Files

- `main.tex`: full paper, including selective-distillation narrative, runtime and quality-speed evidence, and the Gaussian color-adapter negative ablation.
- `paper2_full_writeup.md`: synchronized Markdown write-up.
- `refs.bib`: bibliography.
- `figs/fig_pipeline.tex`: TikZ method and negative-ablation support schematic.
- `figs/fig_pipeline.pdf`: compiled vector pipeline.
- `figs/fig_quality_speed.pdf`: E-211 LPIPS/FID versus runtime quality-speed scatter, generated by `../../scripts/generate_quality_speed.py`.

The negative-ablation schematic uses no invented render outputs. It explains only
the existing E-150 evidence: source-plane recoloring with frozen geometry cannot
add support at newly disoccluded target pixels.

## Checkpoint

See `../MODEL_CARD.md` and run `python3 ../scripts/check_checkpoint.py` to verify
46,371 parameters, output shape `(1, 3, 64, 64)`, and SHA256. Released
checkpoint evaluation is reproducible; exact retraining is partial and not a
self-contained one-command workflow because its external teacher arrays, frame-label JSON, and
original four-scene holdout manifest are not included. See
[`../TRAINING_MANIFEST.md`](../TRAINING_MANIFEST.md) for known settings, unknowns,
and the placeholder-only training template.
